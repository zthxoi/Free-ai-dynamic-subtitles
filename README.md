# Free-ai-dynamic-subtitles
Веб-приложение на базе искусственного интеллекта для автоматической генерации динамических субтитров из видеофайлов. Проект разработан в рамках курсовой работы по направлению «Прикладная математика и информатика».
Основной функционал

    Автоматическое извлечение аудиодорожки из видеоконтейнеров (MP4, MOV, AVI) с помощью FFmpeg.

    Высокоточное распознавание речи и извлечение пословных тайм-кодов (Word-Level Timestamps) с использованием модели OpenAI Whisper-large-v3-turbo.

    Алгоритмическая кластеризация слов в дискретные блоки субтитров с помощью библиотеки PySRT.

    Наложение кастомизированных стилей (шрифт Arial, желтый цвет, контрастная черная обводка) и жесткое вшивание графики в видеопоток под форматы Shorts, Reels и TikTok.

    Интерактивный веб-интерфейс на базе фреймворка Streamlit с поддержкой аппаратного ускорения NVIDIA CUDA.
